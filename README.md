# hingaa

A simple journey and trip planning application.

# Problem Statement

Public transport, in its current state does not solve the struggle of commuting for the average citizen.

Bus timings are unreliable, and inconveniences the commuter to plan their own route ahead of time.

# Solution

An app to facilitate bus travel in a user friendly manner.

Step-by-step instructions to get users to their destinations, while accomodating for their travel preferences.

# Data Sources

AVAS dataset
RTL Bus Routes
Google Maps API
MTCC RTL API
